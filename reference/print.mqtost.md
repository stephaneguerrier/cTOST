# Print Results of (Bio)Equivalence testing in Two Quantiles Setting

Print Results of (Bio)Equivalence testing in Two Quantiles Setting

## Usage

``` r
# S3 method for class 'mqtost'
print(x, ticks = 60, rn = 5, ...)
```

## Arguments

- x:

  A `qtost` object, which is the output of the function 'qtost'.

- ticks:

  Number of ticks to print the confidence interval in the console.

- rn:

  Number of digits to consider when printing the results.

- ...:

  Further arguments to be passed to or from methods.

## Value

The object `x`, invisibly.
