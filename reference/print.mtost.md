# Print Results of (Bio)Equivalence Assessment in Multivariate Settings

Print Results of (Bio)Equivalence Assessment in Multivariate Settings

## Usage

``` r
# S3 method for class 'mtost'
print(x, ticks = 30, rn = 5, ...)
```

## Arguments

- x:

  A `mtost` object, which is the output of one of the following
  functions \`tost\` or \`ctost\`.

- ticks:

  Number of ticks to print the confidence interval in the console.

- rn:

  Number of digits to consider when printing the results.

- ...:

  Further arguments to be passed to or from methods.

## Value

Prints object.
