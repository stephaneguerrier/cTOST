# Print Results of DP-TOST for Proportions

Print Results of DP-TOST for Proportions

## Usage

``` r
# S3 method for class 'prop_test_dp'
print(x, ticks = 30, rn = 5, ...)
```

## Arguments

- x:

  A `prop_test_dp` object returned by `prop_test_equiv_dp`

- ticks:

  Number of ticks to print the confidence interval in the console.
  Default is 30.

- rn:

  Number of digits to consider when printing the results. Default is 5.

- ...:

  Further arguments to be passed to or from methods.

## Value

Prints object invisibly.
