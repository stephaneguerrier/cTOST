# Print Results of (Bio)Equivalence Assessment in Univariate Settings

Print Results of (Bio)Equivalence Assessment in Univariate Settings

## Usage

``` r
# S3 method for class 'tost'
print(x, ticks = 30, rn = 5, ...)
```

## Arguments

- x:

  A `tost` object, which is the output of one of the following functions
  \`tost\` or \`ctost\`.

- ticks:

  Number of ticks to print the confidence interval in the console.

- rn:

  Number of digits to consider when printing the results.

- ...:

  Further arguments to be passed to or from methods.

## Value

Prints object.
